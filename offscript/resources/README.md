# Offscript resources

Shared design knowledge, quality rules, generic sample palettes, licensed fonts and structural
examples used by the engine. Bundled Example Brand names and marks are fictional placeholders.
Project inputs determine identity; reference examples are not customer content or production claims.

`design_principles/` holds cross-track reference data, `design_processes/` track-specific guidance,
and `quality_standards/` shared checks. Website resources are maintained from `design/website/`
through the governance sync package. Keep font attribution and license files intact.
