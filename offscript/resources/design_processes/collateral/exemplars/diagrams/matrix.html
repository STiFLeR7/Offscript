Matrix · classification — rows (teams / areas) × columns (capabilities / criteria), each cell a status (structured visualization, not a diagram). Governing rules: the Diagrams Rulebook (README-DIAGRAMS.md — §9 matrix, §12 style, §13 integrity). Built with CSS Grid on explicit fixed columns — one rowhead column + N capability columns; the header row and header column are styled distinctly (eyebrow caps) and cells are hairline-separated (a 1px grid gap over a keyline ground). Cell content stays concise — a tonal level chip, a short word, or a check; level chips take a soft-clay .tone-* surface, no gradients. Pure HTML/CSS — Grid, no JavaScript, no SVG, no absolute positioning. Doc-scoped (never in colors_and_type.css). Illustrative classification.
