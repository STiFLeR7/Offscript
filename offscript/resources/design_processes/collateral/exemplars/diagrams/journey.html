Journey · transformation across stages, before → through → after (Level 1). Governing rules: the Diagrams Rulebook (README-DIAGRAMS.md — §8 journey, §6 layout intelligence, §10 nodes & connectors, §12 style). Distinct from Process: a Journey shows how the experience / state changes across stages — each node carries a "what changes" line — not merely a numbered sequence. Layout follows the content: horizontal preferred, grid as the fallback for more or longer stages. Stages link with the shared directional connector; the tonal surface may deepen along the arc with stepped .tone-* fills — flat tones, no gradients. Pure HTML/CSS — Flexbox/Grid, no JavaScript, no SVG, no absolute positioning. Doc-scoped (never in colors_and_type.css). Illustrative content.
