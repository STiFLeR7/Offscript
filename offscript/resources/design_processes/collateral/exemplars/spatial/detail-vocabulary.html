1 · Volumetric — iso cube
A full-volume node: the core three faces at cube height. Encodes a discrete entity / service (not a flat layer).
2 · Volumetric — iso cylinder
An ellipse lid + wall at the fixed 2:1 ratio. Encodes a datastore / data source.
3 · Ecosystem cloud — cubes + cylinders
A cluster of volumes = many systems/sources (the Palantir operational-systems pattern). ~8 objects, painted back→front.
4 · Surface texture — woven grid-mesh
A finely-woven platform = throughput / fabric. Built from repeated <line> polylines clipped to the plane — NOT an SVG <pattern> (patterns flake in PDF).
5 · Surface texture — node-graph mesh
Nodes + links on a plane = a network (model integration). Dots reuse the core .spatial-dot.
6 · Embedded cluster — chip rows
Dense rows of small rhombi = sub-modules (a workflow board). Each chip is a real item, not filler.
7 · Console — embedded dashboard UI
A plane carrying embedded UI tiles = a control surface / decision console.
8 · Standing screen — vertical UI plane
A vertical screen with form-field / button rects (Opero browser windows). Sheared into iso via an SVG affine matrix — a 2D transform, print-safe, NOT preserve-3d.
9 · Environment — iso ground grid + droplines
A dashed iso floor (polylines) anchors the scene; dashed droplines tie a floating layer to its position. Both dashed strokes, print-safe.
10 · Connector — curved / sweeping iso path
A bezier connector for long, looping relationships (Palantir's arcs) — alongside the straight hairline+arrow already in the core. Functional, not ornament.
11 · On navy (.cr-band--dark) · volumes, mesh & a focal cube — the same vocabulary, strokes/type lift
Detail vocabulary — the richer primitives the isometric system can render under its own rules (no JS, no preserve-3d, print-safe SVG). Every element encodes real sub-structure (a datastore, a network, a console) — never decoration (Rulebook §14). Volumes are the core faces at cube height / an ellipse-lidded cylinder; textures are repeated polylines, not SVG patterns; screens shear into iso via a 2D affine matrix. Out of scope: bespoke organic objects (a robot arm) and photoreal / refraction shading — those are illustration, not this system. Doc-scoped .spatial-*; copy the parts a document uses.
