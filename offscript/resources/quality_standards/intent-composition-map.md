# Intent → Composition Map (governance — W3-S4 consumption lexicon)

> **Design-team-owned, load-bearing governance.** This is the *only* place the Creative
> Director's **register/mood/pace** (the Intent Brief's `HOW`) is allowed to influence a
> deterministic planner decision: the **lead composition** chosen for each collateral page.
>
> It is a closed keyword lexicon — the same class as the engine's archetype/stats keyword
> maps — **not** open-ended judgment. The planner reads it deterministically: a cue found
> (whole-word, case-insensitive) in `HOW` moves the named composition(s) to the front of the
> page's **existing** candidate set, before the unchanged anti-monotony pick. A `HOW` with no
> listed cue changes nothing (the baseline selection stands). The names on the right are the
> leading labels of the house collateral compositions (see `author-contract.ts`
> `CONTENT_COMPOSITIONS` / `STATS_COMPOSITIONS`); a name that is not a candidate for a given
> page is simply ignored for that page.
>
> **Format (one rule per list item):** `- <cue> → <COMPOSITION NAME>[, <COMPOSITION NAME> …]`
> The cue is a single lowercase word; the right side is one or more composition names in
> preference order. Edit this file to retune how feel maps to layout — no code change.
