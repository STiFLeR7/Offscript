# cta-band

Close with link columns; near-footer hand-off.

## Purpose

The fuller closing band: the primary ask paired with a small set of orienting links, placed as the
page hands off to the footer. It solves the abrupt-goodbye problem from the opposite side of the
shortest banner — when readers arriving at the end may still want a couple of onward paths, it makes
the one ask while offering a tidy set of secondary routes, so the close resolves without stranding
anyone.

## Choose when

- The page is resolving but a near-footer hand-off is wanted rather than an instant end.
- A few onward links (resources, contact, related paths) genuinely help readers not yet ready for the
  single action.
- The audience is mostly decided but benefits from a soft landing into the footer.
- A confident, contrasting close suits the moment, with room for a small link set beside the ask.

## Avoid when

- The only thing left is the single action and a footer follows immediately — reach for the shortest
  banner close instead.
- The onward links would be filler or merely echo the navigation — a link set with nothing real to
  offer dilutes the ask.
- A decorated, flagship finale is wanted — reach for the expressive close used once per page.
- The moment calls for the gentlest possible nudge — reach for a softer mid-page invitation.

## Character

Confident and orderly, lifted by its contrasting surface to mark the close, yet broader than a bare
punctuation mark: the primary action leads while a quiet column of links supports it. It is read at
the point of decision and offers a single action alongside a small, clearly-subordinate set of
routes.

## Composition

It arrives near the end of the page, after the final proof or feature beat, and hands off to the
footer just below. It should not sit beside another call-to-action — competing asks split the close —
and its link set should complement, not duplicate, whatever the footer already carries.

## Contract

Assumes the page has earned the ask and that a few genuine onward paths are worth offering. It expects
one primary action plus a small set of real, useful links; without true routes to list, the columns
are empty scaffolding and the band should give way to a shorter close.

## Judgement

Used well, it closes an argued page with one clear ask and a tidy hand-off into the footer for readers
who want a next path. The tempting misuse is padding the link columns to look substantial, or using
it as a second close beside another ask. With no real onward routes it reads as clutter around the
action; stacked against a competing call-to-action it splits intent and lowers every option's odds.
