# more-solutions

Secondary "also" features after the main set; mid/low page.

## Purpose

Gathers the supplementary "and it also does this" capabilities into one quieter band after the
main feature argument has been made. It solves the everything-at-once problem: when secondary
features would dilute the headline capabilities if shown alongside them, holding them for a
later, lower-emphasis band keeps the primary message clean while still acknowledging the rest.

## Choose when

- The main features have already been presented and there is a worthwhile set of secondary ones.
- The page benefits from a "there's more" beat without promoting those extras to headline status.
- The reader is mid-to-low on the page, past the core argument, browsing for completeness.
- The extras are real and useful but genuinely subordinate to the lead capabilities.

## Avoid when

- It would carry the primary feature argument — reach for a lead feature band; this one is a coda.
- It appears before the main set, where it pre-empts and muddies the headline message.
- There are no real secondary features — an invented "also" list pads the page without adding
  value.

## Character

A quieter, supplementary band of lower emphasis and moderate density: deliberately subordinate to
the main feature sections it follows. The energy is calm and additive — a tidy "and also" — never
competing with the page's lead argument.

## Composition

It belongs after the primary feature set, mid-to-low on the page, and hands off toward
integrations, resources, or the closing ask. It must never precede the main features, and it sits
naturally before a footer-ward wind-down.

## Contract

Assumes a primary feature set is already established that this band supplements, plus a genuine
group of secondary capabilities worth a brief mention. It expects the extras to be real and
relevant — not filler assembled to lengthen the page.

## Judgement

Used well, the page leads with its strongest capabilities and tidies the remaining ones into a
calm later band. The tempting misuse is letting "also" features carry the main weight, or placing
them before the headline set. When the secondary band leads, the reader cannot tell what actually
matters, and the strong features are buried under the merely available.
