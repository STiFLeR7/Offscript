Stat ledger · one stat per row, supporting text + numeral side by side, hairline-ruled — the side-by-side sibling of the metrics wall (.cr-stat-wall, which stacks numeral over caption). The ledger is a grid; each .cr-stat-line is a subgrid row, so the numeral column is shared across rows and every supporting-text cell starts at one x even when figures differ in width. Reuses .cr-stat-value (with .unit) + .cr-stat-sub (default supporting text) or .cr-stat-label (stronger named-metric tier). Numerals are primary dark / inverse text, never an accent; one uniform 44px size per ledger (keep figures short — long values crowd a side-by-side row). Default order is label-first; .cr-stat-ledger--value-first flips it at the container. Dark inversion (white numerals, faint hairlines) is scoped under .cr-stat-ledger on .cr-page--dark / .cr-band--dark. Figures are placeholders.
