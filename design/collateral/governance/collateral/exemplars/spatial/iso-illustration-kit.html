1 · Entity / format cards — colour encodes identity (.tone-*)
Each entity carries its OWN accent family — multi-colour encoding, not one global accent. The colour pairs with the connector/label downstream.
2 · Icon service tiles — a glyph names the capability
A rounded iso tile + a recognizable glyph: gear=config, eye=monitoring, code=build, sync=pipeline, model=ML, db=store, shield=security, lock=encryption, share=integration.
3 · Server stack / repository — stacked racks + status LEDs + platter
Reads as infrastructure/storage: stacked rack slabs with status lights and a disk platter on top — not a bare cylinder.
4 · Padlock — security / encryption
Body cube + U-shackle + keyhole + accent band. The focal one takes the accent. Reads as 'locked', not as a cube.
5 · Shield — protection / trust
Upright shield emblem with a keyhole. The protection metaphor — recognizable label-off.
6 · Orchestration tower / hub — the system core
Tall louvred tower + connector plug = a data/orchestration core. The focal centrepiece of a platform scene.
7 · Knowledge graph — semantic / relationship network
Irregular labelled entities + typed edges + a hub — reads as a knowledge/ontology network, not scattered dots. (In a dense stacked layer the labels drop to keep it compact; the network shape still reads.)
