Accent Color System · Secondary Color Palette — expression layer · 16 Material families × 50–950 · 500 = base

The official Secondary Color Palette — an active expression layer (no longer occasional decoration). It carries information, categorization & visual richness across data-viz series, diagram marks, charts, illustrations, tags, status & category indicators, and supporting UI: cards, data modules, insight blocks, badges, labels, filters, tabs, supporting buttons & backgrounds. Primary (navy + electric) keeps brand authority — primary buttons, navigation, key CTAs, core typography. Target balance per composition: primary 60–70% · secondary 25–35% · neutral 5–15% (directional). Step guidance: 50–300 = fills / surfaces / tags / track · 500–600 = marks / status dots / chart series (500 = base, ringed). Each swatch shows its token, hex, and live contrast vs white: AA ≥ 4.5:1 (body text) · Lg ≥ 3.0:1 (large / UI text only) · — < 3.0:1 (decorative / fill only). The text-safe step varies by family (each row notes its body-text floor) — cool darks clear early, warm & light families need the deep end, and yellow has no AA step (fills / large-text only). A mark shares the exact step token of its label/legend (colour-pairing); secondary colour is not decorative by default — use a purposeful, meaning-driven set so every hue reinforces meaning, hierarchy or categorization.
