Ecosystem · relationships between entities around a core, core ↔ entities (Level 3). Governing rules: the Diagrams Rulebook (README-DIAGRAMS.md — §8 ecosystem, §6 layout intelligence, §10 nodes & connectors, §12 style). The form is fixed by the family: centred — a core entity surrounded by related entities. Built as a 3×3 CSS Grid with the core in the middle cell (emphasised by accent surface and size) and 8 entities facing the centre; the centred arrangement itself carries the "everything relates to the core" read, so there are no radial connector lines — those need SVG / absolute positioning, both disallowed here. Entities stay concise; no gradients. Pure HTML/CSS — Grid with explicit cell placement, no JavaScript, no SVG, no absolute positioning. Doc-scoped (never in colors_and_type.css). Illustrative content.
