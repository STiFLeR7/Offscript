Architecture · a layered system / stack (Level 2). Governing rules: the Diagrams Rulebook (README-DIAGRAMS.md — §8 architecture, §6 layout intelligence, §10 nodes & connectors, §12 style). The form is fixed by the family: a layered vertical stack — never free-form node placement. Each band is a full-width row — a left layer-label rail + a horizontal row of module nodes — and the bands stack directly, hairline-separated, top to bottom. These are layers, not a sequence, so there are no arrows or connectors. Nodes take a soft-clay .tone-* surface, one tone per layer; no gradients. Pure HTML/CSS — Flexbox/Grid, no JavaScript, no SVG, no absolute positioning. Doc-scoped (never in colors_and_type.css). Illustrative agentic platform stack.
