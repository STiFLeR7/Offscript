Roadmap · planned progression — what is committed for Now / Next / Later (or by quarter) (structured visualization, not a diagram). Governing rules: the Diagrams Rulebook (README-DIAGRAMS.md — §9 roadmap, §6 layout intelligence, §12 style, §13 integrity). Built as a timeline / milestone structure: equal-width time-bucket columns over a single hairline axis, each a bucket header + a stack of planned-initiative nodes; columns are pinned equal by CSS Grid and divided by hairline rules. This organizes a plan (forward-looking) — distinct from a Gantt (durations on a calendar) and a Timeline (milestones already reached). Nodes take a soft-clay .tone-* surface; no gradients. Pure HTML/CSS — Flexbox/Grid, no JavaScript, no SVG, no absolute positioning. Doc-scoped (never in colors_and_type.css). Illustrative initiatives.
