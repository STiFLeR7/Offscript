# Website Governance Exemplars — study references

`inspiration/` holds external composition references. They are here to be **studied for principles
only** — composition, visual hierarchy, UI treatment, layering, background use, focal-point strategy —
and **never cloned**. Discard each reference's colours, fonts and content; rebuild in the brand.

These are deliberately **brand-agnostic study material** (the governance side of "exemplars"). For
*brand-compliant* sample pieces — realized pages and sections in this brand — see
`../../../brand-pack/exemplars/`.
