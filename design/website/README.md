# Website design sources

`brand-pack/` contains generic reference tokens, licensed font files, imagery and examples.
`governance/website/` contains authored design methodology. `section-library/sections/` contains
reusable structural templates. These inputs support generation without defining a customer's brand.

Preview source changes through `website-governance-sync`; inspect its plan before updating the runtime
mirror in `offscript/resources/design_processes/website/`. Generated project output belongs in ignored
project workspaces rather than this source directory.
